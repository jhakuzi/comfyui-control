# ComfyUI Control 1.0.0rc1

First release candidate for 1.0. Existing settings, workflows, mappings and mobile
sessions are preserved.

- Tray icon with remembered close-to-tray or quit behavior, adjustable in Settings.
- Larger mobile prompt editor with persistent expand/collapse.
- Optional NFS output, local fallback warnings and a gallery that follows the
  selected destination. Mounting runs in the background when the app launches;
  nothing is enabled at boot and `/etc/fstab` is untouched.
- Scoped permission to start only the configured mount, and guarded setup,
  legacy migration and removal that preserve NAS files and other mounts.
- NFS client installation offer, clearer setup controls, roomier Settings and
  consistent button labels.
- Safe updates of recognizable launch scripts, exact backups and correct output
  arguments. Crash timestamps follow the system timezone and daylight saving.

## Update

Fedora COPR subscribers receive this candidate through:

```bash
sudo dnf upgrade --refresh comfyui-control
```

For a ZIP installation, close the app, extract the new ZIP and rerun `bash install.sh`.
Stop ComfyUI before changing output configuration. If you used the older testing
NFS automount, click **Set up mount** once to migrate it. See the
[NFS guide](../NFS_OUTPUT.md) for fallback behavior and removal.

RPM `1.0.0~rc1-1` sorts below final `1.0.0-1`, so the eventual stable release
will upgrade normally. This GitHub release is marked as a prerelease.
