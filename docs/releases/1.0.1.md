# ComfyUI Control 1.0.1

Fixes LoRA filename fields appearing as text inputs in the Mobile WebUI.

- Mapped LoRA filenames now use installed-model dropdowns. Native node choices
  take priority; custom nodes with text inputs use ComfyUI's LoRA catalogue,
  including subfolders and configured extra model paths.
- **Refresh model choices** updates the cached LoRA list. Refreshing or reopening
  the page preserves unsent selections and strengths. Empty or unavailable lists
  have explanatory messages instead of editable filename fields.
- Existing workflow mappings, enable switches, node connections and saved
  defaults, including custom loader sentinels, are preserved.

## Update

Close the testing copy, then update the installed Fedora app:

```bash
sudo dnf upgrade --refresh comfyui-control
```

Restart the app and refresh the WebUI page. With ComfyUI running, choose
**Refresh model choices**, then expand **LoRAs**.

For ZIP installs, extract the updated app ZIP and rerun `bash install.sh` as
your normal user. Existing settings and mobile sessions carry over.

375 automated tests passed. Chromium and Linux WebKit protocol checks cover
