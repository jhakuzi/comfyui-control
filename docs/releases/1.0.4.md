# ComfyUI Control 1.0.4

This release improves workflow refresh stability and the Desktop WebUI while
keeping one shared controller/backend and the existing yellow theme.

- Refresh model choices without rebuilding unchanged controls. Preserve current
  selections, missing saved values, drafts, mappings, focus, scroll and exact seeds.
- List saved ComfyUI workflows without duplicate imported snapshots. Settings reuse
  adds one selected-image workflow entry at the top; saved workflows stay intact.
- Show configured bypassed LoRAs as unchecked options. Enable or bypass them without
  losing filenames or strength values. Reselect an older saved workflow once to
  recover nodes absent from previously imported snapshots.
- Compact Desktop LoRAs and use -2..2 sliders without restricting numeric inputs.
- Add upward section overlays and prompt/negative-prompt overlays with stable columns
  and panel-aligned bottom borders, icon controls and existing theme/shadows.
- Keep the last completed preview image fixed during submission and generation.
  Display live metrics and reconnect status in the header, with Cancel beside Preview.
- Add Compare to Preview and the enlarged image viewer. Choose one other image from
  a panel-sized gallery and reuse the existing comparison dialog. Thumbnails scroll
  without overlap and show loading indicators instead of flashing filenames.
- Add the existing idle-only VRAM cleanup action to a Desktop broom button. ComfyUI
  itself is unchanged; the timing of its `/free` processing remains server-controlled.
- Preserve Phone presentation and restore its controls after Desktop transitions.

Validation uses Python tests and Chromium/WebKit protocol fixtures. It does not
claim real GPU inference, physical Phone or hardware/NAS compatibility testing.
