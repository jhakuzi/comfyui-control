# ComfyUI Control 1.0.5

This release modernizes the existing Phone WebUI and shares Gallery collections
between Desktop and Phone connected to the same controller and output folder.

- Reuse shared Heart, Edit, Upscale and Delete controls on Phone, with Compare,
  refresh/cleanup icons, prompt chevrons and live step metrics.
- Move Phone completed results above the form as Preview & results. Hide image
  filenames and iPhone save instructions in the viewer. Place Details at the
  bottom and Close over the image; fit controls within the mobile viewport.
- Add Gallery Favourites and Wastebin icons beside Refresh, with heart badges.
  Retain older favourites beyond the recent Gallery and existing saved marks/bin
  entries across devices. Live jobs and prompt history keep their existing privacy.
- Add Clear Bin with confirmation for the displayed images. Permanent deletion
  retains exact-file and ownership checks; failed entries stay visible. Newly
  binned images stay outside an already-confirmed deletion snapshot.
- Fix transient text/layout movement during Desktop heart saves and popup loading.
  Enlarge Desktop collection dialogs while preserving Phone bounds and touch controls.
- Hide the introductory Gallery paragraph on Phone.

Restart the app after upgrading, then reload Desktop and Phone pages for the
shared-library backend and updated shell assets.

Validation uses Python tests and Chromium/WebKit HTTP/filesystem fixtures.
Physical Phone, GPU inference and actual NAS/VPN performance are separate checks.
The reported 15–20 second Phone Gallery loading delay remains unconfirmed and
unchanged in this release.
