# ComfyUI Control 1.1.0

This release adds shared Gallery multi-selection, faster Desktop image browsing
and an optional native installer for the three bundled ComfyUI workflows.

- Select multiple Gallery images on Desktop; right-click for Favourite selected
  or confirmed Delete selected. Phone has a Select icon beside Refresh and a
  tap-and-hold menu on selected images, using the same selection/action logic.
- Compact Gallery layout while retaining Phone touch targets and spacing. Desktop
  selection, Compare, Refresh, Wastebin and Favourites share one toolbar row.
- In the Desktop Gallery image viewer, Left/Right browse, Space toggles selection
  across images and Backspace invokes confirmed single-image Delete. Right-click
  uses the shared bulk menu. Text inputs and Phone behavior are preserved.
- Use themed in-app confirmations for Delete and Clear Bin. Confirmed clearing
  can finish already-missing originals after an NFS device-number change when the
  saved directory inode chain and current mount checks pass. Existing-file
  deletion retains the full fingerprint checks; originals are never removed by
  metadata-only cleanup.
- Install bundled VeryComfy, OfficialComfy-SeedVR_Upscaler and
  VeryComfy_Qwen21_Turbo_EDIT_ONLY workflows from a native dialog beside Settings.
  The same optional dialog is offered after selecting an existing installation
  or finishing fresh setup. Files go into `user/default/workflows`; existing files
  are skipped unless replacement is selected, reviewed and confirmed.
- The installer's Start / open ComfyUI WebUI button checks API readiness. A ready
  server opens directly. Otherwise it offers to start a stopped server through
  the existing controller, then waits until the API is ready before opening.
  Existing starting/running processes are not launched twice. Cancelled/failed
  starts and readiness timeouts do not open the browser.

One-time setup still requires the regular ComfyUI WebUI: load each installed
workflow and use ComfyUI Manager for missing custom nodes, then restart when
prompted. Models and input images must also be available. Copying workflow JSONs
never installs custom nodes/models or executes a workflow.

Restart the application after upgrading and reload Desktop/Phone pages.
Validation uses Python, native Qt and Chromium/WebKit fixtures; the user also
confirmed the installer in a Fedora VM. Real GPU/model inference and physical
Phone/NAS performance are outside automated fixture coverage.
