# ComfyUI Control 1.2.0

This release adds independent workflow batches and a Desktop Gallery visibility
switch, and fixes results that remained on an older image after returning to a tab.

- **Batch Count** now queues separate workflow runs: 4 means four prompts with
  mapped workflow batch inputs set to 1. Random mode draws a fresh seed per run;
  fixed mode retains the exact chosen seed. Status follows Run 1 of 4 through the
  batch. Cancel stops remaining runs using safe per-job cancellation. The existing
  limit of 20 unfinished jobs applies. Durable UUID/seed journals prevent duplicate
  submissions after reconnect/retry; uncertain submissions stop further runs.
- Any browser admitted by your WebUI access rules can Delete saved output images,
  regardless of which browser generated them. The generating-browser restriction
  message is removed. Confirmations, file identity checks and job/metadata privacy
  remain in place.
- Preview & results follows the newest generation in the same browser session.
  Older Comfy Control tabs/windows no longer pin the preview to an earlier job,
  including after reload. Completed-image details remain usable when frequent
  progress updates overtake a full response. Unsent drafts and batch tracking stay.
- Browser tab titles show the current sampling percentage, such as **65%**.
  Loading, processing, completion and connection loss clear it. Existing live
  updates continue during ordinary tab switches; a suspended page reconciles
  safely on return. Verified with Firefox, Chromium and WebKit fixtures.
- A compact Desktop header switch beside **comfy control** includes images in
  dot-prefixed folders when on and hides them when off. It starts off and remembers
  the browser preference. Nested hidden folders are covered, and visible images
  still fill the recent page when newer hidden images dominate output. Favourites
  and comparison follow the setting; Wastebin retains every deleted entry.
  Phone keeps its unfiltered Gallery and original header.
- Remove the obsolete API-format workflow import onboarding message.

## Install or update

Fedora COPR:

```bash
sudo dnf copr enable jhakuzi/comfyui-control
sudo dnf install --refresh comfyui-control
# Already installed:
sudo dnf upgrade --refresh comfyui-control
```

Restart the desktop app after upgrading and reload WebUI pages with Ctrl+Shift+R.
For ZIP installation, extract the attached app ZIP and run `bash install.sh` as
your normal user. Existing configuration and image-library state carry over.

Validation uses disposable application, HTTP/ComfyUI protocol and browser fixtures;
no new real GPU inference, physical Phone or NAS performance claim is made.
