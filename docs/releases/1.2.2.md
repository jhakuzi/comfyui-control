# ComfyUI Control 1.2.2

This release improves support for workflows with connected prompt primitives,
numbered LoRA stacks and combined dimension selectors. The WebUI maps recognized
inputs dynamically and uses an installed dimension choice when there is a unique
whitespace-only match. Unknown or ambiguous inputs remain available for manual
mapping; existing presets keep their saved mappings.

Desktop Generation settings group clearly connected multi-stage sampler controls,
while preserving the existing Phone layout and workflow values. The Gallery's
progress dock floats at the bottom center during generation and stays visible when
scrolling. An old unresolved job no longer overrides a newer completed job's
Generate button feedback.

To apply new automatic mappings to an existing API export, import it again as a new
preset, then set it as the default. The original workflow remains unchanged.

## Update

```bash
sudo dnf upgrade --refresh comfyui-control
```

Restart ComfyUI Control and hard-reload the WebUI. For ZIP installation, extract
the updated app ZIP and run `bash install.sh` as your normal user.
